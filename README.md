### About

I'm a student builder currently deep in **Generative AI and applied LLM systems** — most recently, I built **Nexus Know**, an Enterprise RAG Knowledge Assistant, for the Hexaware Mavericks GenAI Designathon 2026.

I like building things end-to-end: from architecture decisions down to debugging the last environment quirk that stands between a prototype and something that actually runs.

<br/>

### 🔭 Currently Building

**Nexus Know** — an AI knowledge assistant that ingests enterprise documents, retrieves answers by meaning (not keywords), and cites every claim back to its source — with role-based access control baked in from the start.

- 📄 Document ingestion (PDF / DOCX / PPTX)
- 🔍 Semantic search via embeddings + ChromaDB
- 🤖 RAG-grounded generation — no hallucinated answers
- 📎 Citation-backed responses
- 🔐 Role-based knowledge governance + audit logging
